🔌 GitHub 接続設定

トークンは GitHub の Settings → Developer settings → Personal access tokens → Fine-grained tokens で発行し、 対象リポジトリのみに Contents: Read and write 権限を付けてください。
入力した情報はこのブラウザ内（localStorage）にのみ保存され、外部には送信されません。共用PCで使った場合は「接続情報を削除」を押してください。
